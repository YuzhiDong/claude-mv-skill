# 先设计世界，再设计镜头

> 这份文件是本 fork 加的第一份东西。上游没有这一节，因为它来自一次具体的失败：
> 一支 56 秒的 MV，15 个镜头全在同一处屋檐下，背景从第 3 秒到第 50 秒都是同一片深蓝灰。
> 分镜写得很好，表演也对，但用户看完只说了一句：**"场景太多单调，缺乏多样性，还有灰蒙蒙的背景基本上贯穿了全局。"**
>
> 结论：**分镜表管的是"发生什么"，管不了"这是哪儿"。** 少了下面两张表，做出来必是一片糊。

写 `STORYBOARD.md` 之前，先写这几张表，并且让用户看一眼再开工。

**顺序不能反：歌词兑现表 → 场景表 → 色彩表。** 先想"在哪儿"是本末倒置。

## 零、歌词兑现表（最上游的一张，漏了它整片都白做）

> 2026-11 第二次栽在这里。14 行歌词的片子，场景换够了、色相也拉开了、构图骨架也换了，
> 用户仍然指出："23s、25s 我没看到怎么拨开阴霾的，27s 也没看出收集快乐，39s 我们的爱总有时差也没体现出来，
> 这些都是歌词里面明确提到的。" 回头逐行对，**14 行里只有 2 行真的落到了画面上**。
>
> 根因不是不用心，是顺序错了：我**从地点倒推歌词**（先定六个场景，再往每个场景里塞事件），
> 而不是**从歌词正推画面**。地点是结果，不是起点。

**每行歌词先回答三个问题，答不上来就不许进分镜：**

| 问 | 举例（"你让我学会如何拨开阴霾"） |
|---|---|
| ① 这行里有没有**动词**？是什么？ | 拨开 |
| ② 这个动词作用的**东西**长什么样？能被手碰到吗？ | 阴霾 = 一层盖在画面上的灰，有实体、有边、能被撕开 |
| ③ 谁做这个动作，做完之后**画面哪里变了**？ | 他先撕开一道，她学着撕开第二道；被撕开的地方直接露出彩色 |

三问答完，画面自己就出来了。答不上来的典型症状是**用氛围代替动作**：
"拨开阴霾"给一个"擦窗户"，"收集快乐"给一面"照片墙"——同类气氛，但歌词要的那件事没有发生。

### 三条硬规矩

1. **抽象名词必须先在画面上变成实物。** 阴霾、快乐、时差、炙热、挫败——这些词不能靠调色和表情暗示，
   得有一个**有形状、有重量、能被手碰到**的东西承载它。阴霾是一层能撕的灰幕，快乐是能装进罐子的光点，
   时差是同一张长椅被切成两半。**先造物，再给动作。**
2. **一句歌词至少一个可见变化。** 不是"这镜的气氛对"，而是**这一句唱完，画面里多了一样/少了一样/变了一样**。
   全片过一遍，凡是找不到变化的行，就是没兑现的行。
3. **对偶句必须两个动作都在。** "将快乐全都收集 / 将不开心全都淘汰"是一个句子里的两个反向动作，
   只画"收集"等于只兑现了一半。看到"…全都…全都…""…却…""…也…"这类结构，先数动作个数。

### 自检：一行一行打勾

分镜写完，把歌词和分镜并排贴出来，逐行标注：这行的动作在**哪一镜、第几秒**发生。
标不出来的行，不许含糊过去——它就是观众看完会说"这里我没看懂"的那一处。

```
0  我们都是渺小真实存在      → S01 极远景，人在巨大夜景里只占 1/18 高度   ✓
1  祈愿小世界里不只有挫败    → S02 娃娃机抓空 + 闭眼许愿（两个动作）      ✓
6  你让我学会如何拨开阴霾    → S07 他撕开灰幕 / 她撕开第二道              ✓
7  将快乐收集 将不开心淘汰   → S08 光点装罐 + 灰石丢桶（两个动作）        ✓
12 我们的爱总有时差          → S13 分屏：左夜右晨，背靠背碰不到          ✓
```

## 一、场景表

**一段（2–4 个镜头）换一处空间。一支 2 分钟以内的片子，至少 4–6 处。**

一个地点讲完全片，即使在剧作上成立（三一律），视觉上也是失败的——观众会以为你没画完。

每处写四样东西：

| 列 | 写什么 | 为什么 |
|---|---|---|
| 地点 | 一句话，具体到能画 | "檐下"不够，要写"老街店铺的屋檐下，墙在左，雨帘在右" |
| 空间层次 | 前景 / 中景 / 远景各是什么 | 没有三层，画面就是平的 |
| 镜头运动 | 推 / 拉 / 横移 / 跟 / 固定 | 同一段里不要全用同一种 |
| 出现时段 | 对应的歌词或秒数 | 跟音乐段落对齐 |

**示例**（雨天题材，六处）：

```
1. 檐下      前景 墙脚水洼 · 中景 人 + 收起的伞 · 远景 雨帘        固定 + 横移   0–8.6s
2. 湿石板街  前景 路灯杆 · 中景 石板路与两侧墙 · 远景 消失点        跟拍推近      8.6–15.8s
3. 河边栏杆  前景 石栏 · 中景 水面 · 远景 对岸楼影                  横移          15.8–22.7s
4. 桥洞      前景 砖拱（包围）· 中景 人 · 远景 洞口的亮             低机位固定    22.7–28.9s
5. 天台      前景 屋脊 · 中景 人 · 远景 天际线 + 天                 上摇 + 拉远   28.9–38.2s
6. 雨后檐下  同 1，但光变了                                          固定 + 拉远   38.2–56.2s
```

第 6 处回到第 1 处是**有意的**——开头结尾押韵。押韵靠"同一个地方换了光"，不靠"又画一个新地方"。

## 二、色彩表

即使整片都在下雨、都在夜里，也必须有明确的色彩弧线。**相邻两段的色相必须拉开。**

| 段落 | 主色（给一个 hex） | 光（方向 / 来源 / 强弱） |
|---|---|---|
| 独自 | `#6E8AA0` 冷青灰 | 无方向，平光 |
| 遇见 | `#E8AA38` 暖黄 + 褐 | 街边一盏店招灯，湿地面反光 |
| 并肩 | `#3E5E66` 青绿 + `#E8A45E` 暮橙 | 暮色从水面返上来 |
| 最快乐 | `#5A4436` 深褐 + 灯泡黄 | 拱顶一颗灯泡，唯一光源 |
| 高潮 | `#232B58` 深蓝 + 朱红金 | 烟花强光扫过，有光源实体 |
| 之后 | `#E8E2D6` 米白 → `#BFD8DA` 天青 | 天光，软、亮 |

两条硬规矩：

1. **不要连续三段用同一个色系。** 冷暖要交替：冷 → 暖 → 冷 → 暖 → 冷。
2. **每段都要有一个"光源实体"**（灯泡、店招、烟花、天光）。没有实体光源，画面就是灰的。

### 明度由歌定，不由题材定

> 踩过：一支欢快的歌，做成了灰蒙蒙的夜戏。用户的评价只有一句："这个歌听起来是欢快的，但 mv 的风格偏灰暗色调。"

**先把情绪定下来，再定明度，最后才定色相。** 顺序反了就会出事：题材是"夜班""海边""离别"，
手就自动往深蓝灰、低饱和、低明度上走——**这是美术习惯，不是歌的要求**。

| 歌的情绪 | 明度基线 | 允许压暗的地方 |
|---|---|---|
| 轻快 / 明亮 / 少女 | **高**。主色明度 65–85%，饱和 45–70%，靠暖色和糖果色区分段落 | 最多一段，且必须有歌词理由（"最灰暗的日子"） |
| 温柔 / 抒情 | 中高。明度 55–75%，留一处亮部做呼吸 | 一两段 |
| 沉重 / 挽歌 | 中低 | 不受限 |

三条判据：

1. **全片抽帧的平均明度**应当跟歌的情绪同向。欢快的歌，平均值不该低于 55%。
2. **每一段压暗都要能引用一句歌词。** 引不出来就是手在习惯性变暗——那种暗观众读成"没画完"。
3. **暗部必须有亮的东西在里面。** 唯一的灰段（停电的屋子）里要有一根蜡烛、一块手机屏——
   全灰的画面不是暗，是脏。

配色时先填这张表，比临时挑色靠谱：

| 段落 | 主色 | 明度% | 饱和% | 为什么是这个色（引歌词或情绪） |
|---|---|---|---|---|

## 三、构图骨架

**光换地点不够，骨架也得换。**

第一遍改完六处场景，用户仍然说"单调"——因为六个场景全都长成"左侧一块暗体 + 中间人物 + 右侧雨"。
观众看到的不是六个地方，是同一张构图换了墙纸。

每处场景挑一个骨架，并且**相邻两处不要用同一个**：

| 骨架 | 怎么分画面 | 适合 |
|---|---|---|
| 左墙 + 右空 | 竖着切三分，一侧是实体，一侧是空气 | 檐下、门洞 |
| 对称纵深 | 消失点在正中，两侧往中间收 | 街道、走廊、桥 |
| 横向分层 | 前景 / 中景 / 远景 / 天，四层横着摞 | 河边、海边、站台 |
| 包围式 | 四周是暗体，中间掏一个亮的口 | 桥洞、隧道、窗 |
| 上下分层 | 上三分之二是天，下三分之一是地 | 天台、山顶、广场 |
| 全屏 | 不留边界，整个画面是一种材质 | 水面、特写、梦境 |

## 三·五、换景不等于换地点

> 踩过：七处场景、七个色相、七种骨架构图，用户仍然说"场景切换单调，缺乏创意性""场景里的元素过于单调"。
> 因为七个场景全都是**同一个尺度、同一种空间逻辑**：中景、平视、人站在景物前面。
> 观众看到的不是七个地方，是同一张明信片换了七张底图。

### 换景的四种维度，至少动两种

| 维度 | 变化方式 | 例子 |
|---|---|---|
| **尺度** | 极远 ↔ 极近，中间留跳变 | 俯拍全城的微小窗口 → 眼睛里映着的海 → 一颗光点的特写 |
| **空间逻辑** | 画面本身被切开 / 穿透 / 翻转 | 分屏（左夜右晨）、从眼睛里看出去、幕布被撕开、水面倒影取代实景 |
| **视点高度** | 平视 ↔ 俯视 ↔ 仰视 ↔ 贴地 | 贴地看石阶上的水 → 仰拍路灯 → 俯拍整条街 |
| **载体** | 画面挂在什么上 | 电视雪花屏里、照片里、玻璃倒影里、别人瞳孔里 |

**同一段里不要连用同一种尺度。** 三段中景接三段中景，就是"单调"的直接来源。

### 元素密度：每景至少 6 件可辨物件

空画面的问题不是"不够满"，是**没有 3 秒钟以上的观看价值**——观众一眼看完就没得看了。

- **每个场景列一张清单，写满 6–8 件**，其中至少 2 件是**前景**（压住画面下缘或一侧），
  至少 1 件会**动**（蒸汽、风里的布、水波、飞虫）。
- 物件要能被认出来：货架上的商品要有个别形状（不是一排方块），墙上的钟要有时针分针，
  地上的水渍要有形状。**"装饰性噪声"不算元素**（撒一把小点不等于丰富）。
- 前景物件是廉价的空间感：栏杆、门框、垂下的电线、别人的肩膀，一加就有纵深。

| 场景 | 6–8 件（★=前景，~=会动） |
|---|---|
| 便利店夜 | 货架三层 / 关东煮锅~ / 冷柜玻璃 / 收银机 / 墙钟 / ★门框 / ★地上的水渍 / ★门口的娃娃机 |
| 堤坝 | 栏杆立柱★ / 防波堤方块 / 海平线 / 远处灯塔 / 海鸥~ / 浪花~ / ★脚下的裂纹 |
| 天台 | 晾衣绳~ / 五六件衣服~ / 水塔 / 女儿墙★ / 天线 / 鸽子笼 / 串灯~ / 远处的机场灯~ |

## 四、景别：场景要成为主体，相机就得退

**这是第二个坑。** 换完场景后相机如果还在 `zoom 1.0–1.16` 的中景上，
景物会全被挤到画面边缘，等于白换。

| 用途 | `zoom` | 人物占画面高度 |
|---|---|---|
| 建立镜头 / 场景镜头 | **0.74–0.92** | < 1/4 |
| 常规表演镜头 | 1.0–1.3 | 1/4 – 1/2 |
| 特写 | 1.6–2.5 | > 1/2 |

**一个 56 秒的片子，至少要有三分之一的镜头让人物小于画面高度的 1/4。**
否则观众永远不知道自己在哪儿。

## 五、自检：一张图判断整片是不是"一片糊"

出片前（或者每做完一段），抽全片帧拼一张 contact sheet：

```bash
ffmpeg -y -v error -i out/video.mp4 -vf "fps=1.4,scale=228:-1,tile=8x10" -frames:v 1 out/check/all.jpg
```

然后看这张图，问三个问题：

1. **能一眼数出几处地方？** 少于 4 处，回去加场景。
2. **相邻两段颜色一样吗？** 一样，回去改色彩表。
3. **每行的构图是不是同一个形状？** 是，回去换骨架。

这张图比任何单帧检查都有效——它暴露的正是"观众看完成片之后的整体印象"。

## 七、先选一个故事形状（结构）

分镜之前先定"这支片子是什么形状的"。四种骨架，各自有代价：

| 结构 | 形状 | 适合 | 代价 |
|---|---|---|---|
| **回环** | 首尾同一场景，人物状态相反 | 失去 / 遗憾 / 时间流逝 | 中间必须真的"变过"，否则只是原地绕圈 |
| **镜像** | 前后两半互为倒影（同一动作，换人换结果） | 关系 / 因果 / 报应 | 需要精确重复，一笔不对就散 |
| **双线** | 两条线平行剪辑，最后交汇或永不相交 | 分隔 / 异地 / 两条人生 | 每镜都要能立刻认出"这是谁那条线"，色/景/构图必须区分 |
| **单线递进** | 一路向前，场景不回头 | 成长 / 逃离 / 一天之内 | 最容易平淡，需要每段抬一档 |

选回环就要接受：**结尾不能加新东西**，只能加"同一个东西的另一面"。开场也要"干净"，别把话说完——
首镜说得越少，尾镜回来时回响越大。

## 八、符号接力：把一个形状用三镜

因果讲的是"A 之后拍 B"，符号接力讲的是**同一个东西换了三次形**。这是把几镜焊成一条链最省的手段。

- **做法**：挑一个可变的形（裂缝、光斑、一条线、一个圆），让它在前一镜的**边缘**出现，
  下一镜变成主体的一部分，第三镜变成另一种东西。
- **触发点必须长在前一镜里**。裂痕得从窗框渗进来，不能凭空出现在画面中央；凭空出现就退化成特效。
- **一链不超过三镜**。超过观众会忘掉起点，读成"又是一堆符号"。
- **符号接力优先于换场理由**。宁可少换一个景，也要保住这条链——链断了，情绪就断了。
- **反面**：每镜换一个新符号（雨 → 灯泡 → 爱心 → 星星），那是贴纸拼盘。

例：水从伞沿滴下来 → 同一道水痕爬上窗玻璃、裂成一道缝 → 缝张开成两人之间的空 →
空里那颗心沿同一条缝碎开。四镜共用"一条缝"。

## 九、什么时候可以跳过这张表

- 片长 < 15 秒（一个场景足够）
- 用户明确要求"就一个固定镜头"
- 这是某支片子的一个片段，不是完整作品

除此之外，不要跳。
