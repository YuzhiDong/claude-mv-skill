# 从歌到镜头：设计顺序与判据

> 这份文件改到第四版了。每一版都来自一次具体的失败：
>
> 第一版（只有分镜）→ 15 镜全在同一处屋檐下，用户说"**场景太多单调，背景灰蒙蒙贯穿全局**"。
> 第二版（加场景表 + 色彩表）→ 场景换够了，用户说"**场景切换单调，缺乏创意性；元素过于单调**"——
> 七个场景全是同一尺度、同一视点，等于同一张明信片换了七张底图。
> 第三版（加歌词兑现表）→ 14 行歌词只有 2 行真落地，用户说"**拨开阴霾、收集快乐、时差都没体现**"。
> 第四版（本版）修的不是"又漏了什么"，是前三版**互相打架**和**过拟合**的地方。
>
> 教训的价值不在条数，在于它们不该互相抵消。

---

## 零、先看这张表：规则打架时按这个顺序裁决

前三版最大的问题不是缺规则，是规则太多且**没有优先级**。举一对真实的冲突：

- 「符号接力优先于换场理由，宁可少换一个景」
- 「一段换一处空间，2 分钟以内至少 4–6 处」

方向相反，文档没写谁先。执行时只能临场发挥，同一个问题两次给出不同答案——那方法论就白写了。

**遇到冲突，从上往下，第一条能裁定的说了算：**

| # | 优先级 | 含义 |
|---|---|---|
| C1 | **节奏 > 歌词语义** | 镜头在哪切由节奏定，不由"这句唱完了"定。见第一节 |
| C2 | **引擎能力 > 审美愿望** | 引擎做不到的，降级为可执行的近似做法并标注，不写进分镜当要求 |
| C3 | **全片明度基线 > 单段色相偏好** | 某一段想压暗，先看它违不违反全片基线；违反就得能引用一句歌词 |
| C4 | **兑现配额 > 每句都兑现** | 允许少数行不兑现氛围，但配额有上限。见第二节 |
| C5 | **符号链完整 > 场景数量** | 这条链要跨段，就允许这一段不换景 |
| C6 | **极特写 / 极远景 > 元素密度** | `zoom ≥ 1.6` 或 `≤ 0.72` 的镜头豁免物件数量指标 |

## 一、节奏预算（最上游，比歌词更早）

> 这是前三版都没意识到的问题：16 个镜头的时长**全部由歌词行的起止时间决定**——
> 歌词换行，镜头就换。后果是这支片子里**永远不可能有长镜头，也永远不可能有快切**，
> 因为最短的歌词行也有 2 秒多，最长的一行也只有 7 秒。
>
> 而 MV 的感染力很大一部分来自**镜头长度的对比**：三秒静、半秒切、五秒长镜。
> 一对一绑死歌词，这个维度就被结构性地锁死了。

### 切分依据：节拍，不是句号

**一行歌词可以配 1 个镜头、3 个镜头，或者两个镜头共用一行。**
切点优先落在**节拍**（BPM 推出来的拍点）和**动作完成点**上，歌词换行只作参考。

三种合法切法：

| 切法 | 什么时候用 | 例 |
|---|---|---|
| 一行一镜 | 抒情、陈述句 | "我们都是渺小真实存在" |
| 一行多镜 | 密集动作、副歌、情绪爆发 | "将快乐收集 / 将不开心淘汰" → 装罐 3 短镜 + 丢桶 2 短镜 |
| 一镜跨行 | 情绪需要停留、长镜头呼吸 | 烟花定格跨两行 |

### 三档镜头长度（56 秒片子的配额）

| 档 | 时长 | 作用 | 全片至少 | 至多 |
|---|---|---|---|---|
| 短 | 0.5–1.2s | 切出节奏、加速 | **5 个** | — |
| 中 | 2–3.5s | 叙事主体 | — | — |
| 长 | 5–8s | 情绪停留、长镜头 | **2 个** | 4 个 |

**反面（前三版就是这样）**：16 镜全落在 2.6–3.8 秒，平均 3.5 秒。
观众的感觉是"从头到尾一个速度"，说不出哪里不对，但会觉得"平"。

### 时长按**净时长**算——转场要占账

三档里的秒数是**画面真正能被看见的时间**，不含转场。一次覆盖式转场 0.6–0.9 秒，
是从出镜镜头的尾巴和入镜镜头的开头各切走 0.3–0.45 秒拼出来的：

| 镜头 | 账面 | 两侧都有覆盖式转场 | 实际可读 |
|---|---|---|---|
| 短 | 1.1s | −0.8s | 0.3s —— 读不出任何东西 |
| 中 | 3.0s | −0.8s | 2.2s —— 刚好够两条 reads |
| 长 | 5.5s | −0.8s | 4.7s —— 几乎无感 |

所以 **短镜之间一律硬切**，覆盖式转场只放在中镜和长镜的接缝上，时间从长镜里扣。
填下面那张表时写的是净时长：写账面数字等于虚报，做完才发现"这一镜怎么什么都没看清"。

### 先填这张表，再写分镜

| 段落 | 对应歌词行 | 镜头数 | 长度档位 | 切点（拍 / 秒） |
|---|---|---|---|---|
| 前奏 | — | 2 | 长 + 短 | 0 / 4.8 |
| 副歌 | 6–7 | 5 | 短 ×4 + 中 | 按八分音符切 |

## 二、歌词兑现：四种方式，不是一种

> 第三版的判断下得太窄了：它把"没兑现"一律归因为"没造出实物"，
> 结果是**每句歌词都得变成一次道具操作演示**，片子会越来越像图解动画。
>
> 而本片自己就在用规则之外的手段，而且效果比动作型更好——
> 「眼睛里看到广袤无垠的大海」做成瞳孔极特写反向拉出成实景（**尺度型**），
> 「时间停了一下」做成烟花静止只有风还在动（**时间型**）。这两种都不符合"能被手碰到"。

**四种合法的兑现方式，任选其一即可：**

| 方式 | 手段 | 例 | 配额 |
|---|---|---|---|
| **动作型** | 造一个有形状、有重量、能被手碰到的实物，让角色对它施力 | 灰幕被五指抓住往下扯 | **≤ 全片 60%** |
| **尺度型** | 极远 ↔ 极近的跳变，靠景别落差兑现 | 瞳孔里的海 → 拉出成真实海面 | 自由 |
| **时间型** | 停顿、定格、倒放、慢到不像在动 | 烟花停在空中，只有头发和海浪还在动 | 自由 |
| **重复型** | 同一动作换人换结果，靠对比兑现 | 他撕一道、她撕第二道 | 自由 |

动作型之所以要配额：它是四者里**最"说明性"**的一种。全片超过六成都在"抓一个东西、塞一个东西、撕一个东西"，
片子就变成了流程演示，画面本身没有呼吸的地方。

### 三问答（针对动作型，答不上来就不许进分镜）

| 问 | 举例（"你让我学会如何拨开阴霾"） |
|---|---|
| ① 这行里有**动词**吗？是什么？ | 拨开 |
| ② 这个动词作用的**东西**长什么样？能被手碰到吗？ | 阴霾 = 一层盖在画面上的灰，有实体、有边、能被撕开 |
| ③ 谁做、做完之后**画面哪里变了**？ | 他先撕一道，她学着撕第二道；撕口里直接露出彩色 |

答不上来的典型症状是**用氛围代替动作**："拨开阴霾"给一个擦窗户，"收集快乐"给一面照片墙——
气氛同类，但歌词要的那件事没有发生。

### 两条仍然成立的硬规矩

1. **一句歌词至少一个可见变化。** 不是"这镜气氛对"，而是这一句唱完，画面里**多了一样 / 少了一样 / 变了一样**。
2. **对偶句两个动作都得在。** "将快乐全都收集 / 将不开心全都淘汰"——只画收集等于只兑现一半。
   看到"…全都…全都…""…却…""…也…"这类结构，先数动作个数。

### 允许不兑现的行

有些行是纯情绪句，硬兑现只能造出一个假道具。**全片最多 2 行可以不兑现**，条件是：

- 必须**紧邻一个强兑现行**（前一行或后一行），不能连着两行都不兑现；
- 不兑现那一行要在表里写清理由（"过渡句，靠上一镜的余温承接"），不许空着。

### 每镜 reads 上限：3 条

`reads` = 观众依次必须看懂的东西。**一个镜头超过 3 条 reads 就拆镜。**

反面教材就在本片：S07 写了 5 条 reads，镜头只有 2.97 秒，平均 **0.59 秒一条**。
写的时候觉得排得下，真渲出来必然糊——人看懂"手抓住、往下扯、口子张开"至少需要 1.2 秒。

## 三、场景：按段给预算，不按镜给指标

**一段（2–4 个镜头）换一处空间。一支 2 分钟以内的片子，4–6 处。**

一个地点讲完全片，即使在剧作上成立（三一律），视觉上也是失败的——观众会以为你没画完。

### 换景不等于换地点：四个维度，至少动两种

| 维度 | 变化方式 | 例 |
|---|---|---|
| **尺度** | 极远 ↔ 极近，中间要留跳变 | 俯拍全城的微小窗口 → 瞳孔里的海 → 一颗光点的特写 |
| **空间逻辑** | 画面本身被切开 / 穿透 / 翻转 | 分屏、从眼睛里看出去、幕布被撕开、倒影取代实景 |
| **视点高度** | 平视 ↔ 俯视 ↔ 仰视 ↔ 贴地 | 贴地看石阶的水 → 仰拍路灯 → 俯拍整条街 |
| **载体** | 画面挂在什么上 | 电视雪花屏里、照片里、玻璃倒影里、别人瞳孔里 |

**同一段里不要连用同一种尺度。** 三段中景接三段中景，就是"单调"的直接来源。

### 每段的预算（不是每镜）

| 项目 | 该段累计要求 | 为什么从逐镜改成按段 |
|---|---|---|
| 可辨认物件 | **6–8 件** | 逐镜要求会逼着每个镜头都塞满，而一段里本来就有建立镜头和特写，容量不同 |
| 前景物件 | **≥ 2 件** | 廉价的空间感：栏杆、门框、垂下的电线、别人的肩膀 |
| 会动的元素 | **≥ 1 件** | 蒸汽、风里的布、水波、飞虫 |
| 建立镜头 | **≥ 1 个**（`zoom` 0.74–0.92） | 让观众知道自己在哪儿 |

**豁免（C6）**：`zoom ≥ 1.6` 的极特写和 `zoom ≤ 0.72` 的极远景不参与物件计数。
一只眼睛的特写里没有六件物件，这不是缺陷。

物件要能被认出来：货架上的商品要有个别形状（不是一排方块），墙上的钟要有时针分针，地上的水渍要有形状。
**"装饰性噪声"不算元素**（撒一把小点不等于丰富）。

| 场景 | 6–8 件（★=前景，~=会动） |
|---|---|
| 便利店夜 | 货架三层 / 关东煮锅~ / 冷柜玻璃 / 收银机 / 墙钟 / ★门框 / ★地面积水 / ★门口娃娃机 |
| 堤坝 | ★栏杆立柱 / 防波堤方块 / 海平线 / 远处灯塔 / 海鸥~ / 浪花~ / ★脚下裂纹 |
| 天台 | 晾衣绳~ / 五六件衣服~ / 水塔 / ★女儿墙 / 天线 / 鸽子笼 / 串灯~ / 远处机场灯~ |

### 景别：场景要成为主体，相机就得退

| 用途 | `zoom` | 人物占画面高度 |
|---|---|---|
| 建立镜头 / 场景镜头 | **0.74–0.92** | < 1/4 |
| 常规表演镜头 | 1.0–1.3 | 1/4 – 1/2 |
| 特写 | 1.6–2.5 | > 1/2 |

一个 56 秒的片子，至少要有**三分之一**的镜头让人物小于画面高度的 1/4。否则观众永远不知道自己在哪儿。

## 四、色彩：明度由歌定，不由题材定

> 踩过：一支欢快的歌，做成了灰蒙蒙的夜戏。用户只说了一句：
> "**这个歌听起来是欢快的，但 mv 的风格偏灰暗色调。**"

**先把情绪定下来，再定明度，最后才定色相。** 顺序反了就会出事：题材是"夜班""海边""离别"，
手就自动往深蓝灰、低饱和、低明度上走——**这是美术习惯，不是歌的要求**。

| 歌的情绪 | 明度基线 | 允许压暗的地方 |
|---|---|---|
| 轻快 / 明亮 / 少女 | **高**。主色明度 65–85%，饱和 45–70%，靠暖色和糖果色区分段落 | 最多一段，且必须能引用一句歌词 |
| 温柔 / 抒情 | 中高。明度 55–75%，留一处亮部做呼吸 | 一两段 |
| 沉重 / 挽歌 | 中低 | 不受限 |

三条判据：

1. **全片抽帧的平均明度**应当跟歌的情绪同向。欢快的歌，平均值不该低于 55%。
2. **每一段压暗都要能引用一句歌词。** 引不出来就是手在习惯性变暗，那种暗观众读成"没画完"。
3. **暗部必须有亮的东西在里面。** 唯一的灰段里要有蜡烛、手机屏——全灰的画面不是暗，是脏。

| 段落 | 主色（hex） | 明度% | 饱和% | 光（方向 / 来源 / 强弱） | 为什么是这个色 |
|---|---|---|---|---|---|

两条硬规矩：**不要连续三段用同一个色系**（冷 → 暖 → 冷 → 暖）；**每段都要有一个光源实体**（灯泡、店招、烟花、天光）——
没有实体光源，画面就是灰的。

## 五、结构与骨架

### 故事形状：四种，各自有代价

| 结构 | 形状 | 适合 | 代价 |
|---|---|---|---|
| **回环** | 首尾同一场景，状态相反 | 失去 / 遗憾 / 时间流逝 | 中间必须真的"变过"，否则只是原地绕圈 |
| **镜像** | 前后两半互为倒影 | 关系 / 因果 / 报应 | 需要精确重复——**注意 C2，见第六节** |
| **双线** | 两条线平行剪，最后交汇或永不相交 | 分隔 / 异地 / 两条人生 | 每镜都要能立刻认出"这是谁那条线" |
| **单线递进** | 一路向前，场景不回头 | 成长 / 逃离 / 一天之内 | 最容易平淡，需要每段抬一档 |

选回环就要接受：**结尾不能加新东西**，只能给同一个东西的另一面。开场也要干净——首镜说得越少，尾镜回响越大。

### 构图骨架：六种，相邻不重复

| 骨架 | 怎么分画面 | 适合 |
|---|---|---|
| 左墙 + 右空 | 竖着切三分，一侧实体一侧空气 | 檐下、门洞 |
| 对称纵深 | 消失点在正中，两侧往中间收 | 街道、走廊、桥 |
| 横向分层 | 前 / 中 / 远 / 天，四层横着摞 | 河边、海边、站台 |
| 包围式 | 四周暗体，中间掏一个亮的口 | 桥洞、隧道、窗 |
| 上下分层 | 上三分之二是天，下三分之一是地 | 天台、山顶、广场 |
| 全屏 | 不留边界，整个画面是一种材质 | 水面、特写、梦境 |

## 六、符号接力：只能做近似，必须标清楚

> 上一版写了「同一个形在三镜里精确衔接」，但引擎**没有跨镜形状传递的机制**，
> 每次都得手写两遍，第二遍必然有偏差。要求了做不到的事，等于没要求（C2）。

**可行做法：近似 + 显式标记。**

- 挑一个**好近似**的形：圆、直线、竖缝、光点、一束光。不要挑不规则曲线。
- 把它写成共享常量放进 `cast.js`（比如 `MOTIF.spot` = 半径与色值），三镜都引用同一个常量。
  这样至少**尺寸和颜色是精确的**，只有位置和角度是手调的。
- 位置衔接靠"长在前一镜的边缘"：出画点在哪，下一镜就从对应侧进来。在分镜里写明该镜的**具体坐标或方位词**。
- **一链不超过三镜**。超过观众会忘掉起点，读成"又是一堆符号"。
- **反面**：每镜换一个新符号（雨 → 灯泡 → 爱心 → 星星），那是贴纸拼盘。

**镜像结构同理**：不做逐帧倒放，做"两镜共用一套参数、只换人"。参数进常量，人进变量，
允许镜头运动有 10–20% 的差异——观众要的是"一样的感觉"，不是像素级一致。

## 七、自检

### 机器能查的（出片前跑）

```bash
# 全片抽帧拼图：每 1.4 秒一帧
ffmpeg -y -v error -i out/video.mp4 -vf "fps=1.4,scale=228:-1,tile=8x10" -frames:v 1 out/check/all.jpg
```

看这张图，问三个问题：

1. **能一眼数出几处地方？** 少于 4 处，回去加场景。
2. **相邻两段颜色一样吗？** 一样，回去改色彩表。
3. **每行的构图是不是同一个形状？** 是，回去换骨架。

### 只能人眼看的（逐条打勾）

- [ ] 节奏：数一遍镜头时长（**净时长，已扣转场**），短镜 ≥5、长镜 ≥2？全都落在 2–3.5s 就是"平"
- [ ] 转场：每缝的类型在分镜里写死了吗（硬切 / 覆盖 / 闪 / 匹配 / 相机带走）？覆盖式总数 ≤8？
      盖满那一瞬落在歌词换行间隙里吗？短镜之间是硬切吗
- [ ] 歌词：逐行标出"哪一镜、第几秒"，标不出的行不超过 2 行，且不连着
- [ ] 兑现方式：动作型是否 ≤60%？有没有至少一个尺度型和至少一个时间型
- [ ] reads：每镜 ≤3 条？随手挑三镜，按秒数念一遍，看是否来得及
